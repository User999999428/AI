# 외부 데이터셋: CEW (Closed Eyes In The Wild)

2단계 눈 감김 판단(EAR)이 실제 사진에서 얼마나 정확한지 검증할 때 쓰는 데이터셋입니다.

## ⚠️ 라이선스와 이용 조건 (꼭 지킬 것)

- **연구·비상업적 목적으로만** 이용할 수 있습니다.
- **재배포 금지**: 데이터셋 파일을 다른 사람에게 주거나, 인터넷(GitHub 포함)에 올리면 안 됩니다.
- 그래서 이 프로젝트에서는 데이터를 `data/` 폴더에만 두고, `.gitignore`로 GitHub에 올라가지 않게 막았습니다.
- 사진 일부를 잘라 저장소에 넣거나 다른 폴더에 복사하는 것도 하지 않습니다.
- 데이터셋을 쓴 결과를 발표·보고서에 쓸 때는 아래 **출처(논문)**를 밝힙니다.
- 보고서에 데이터셋 속 얼굴 사진을 직접 넣지 않습니다. 숫자 결과(정확도 표 등)만 씁니다.

> 위 조건은 데이터셋 배포처의 이용 조건을 따릅니다. 공식 페이지의 원문을 직접 확인하세요.
> (이 문서를 쓸 때 개발 환경에서는 공식 페이지에 접속할 수 없어 원문을 옮기지 못했습니다.)

## 출처

- **데이터셋 이름**: CEW (Closed Eyes In The Wild)
- **만든 곳**: 중국 난징항공항천대학교(NUAA) Xiaoyang Tan 교수 연구실
- **논문 (인용할 때 사용)**:
  F. Song, X. Tan, X. Liu, S. Chen,
  "Eyes closeness detection from still images with multi-scale histograms of principal oriented gradients,"
  *Pattern Recognition*, vol. 47, no. 9, pp. 2825–2838, 2014.

> 논문의 권호·쪽수는 보고서에 쓰기 전에 공식 페이지나 논문 검색(Google Scholar 등)으로 한 번 더 확인하세요.

## 이 프로젝트에서 쓰는 방법

### 1. 데이터 넣기 (컴퓨터마다 직접)

내려받은 데이터를 아래 위치에 압축 해제합니다.

```
AI/
└── data/                                        ← GitHub에 안 올라감
    └── dataset_B_FacialImages_highResolution/
        ├── (눈 감은 얼굴 사진 폴더)   예: ClosedFace
        └── (눈 뜬 얼굴 사진 폴더)     예: OpenFace
```

검증 스크립트는 **폴더 이름**으로 눈 뜬/감은 사진을 구분합니다.
- 이름에 `close`가 있으면 → 눈 감은 사진
- 이름에 `open`이 있으면 → 눈 뜬 사진

실제 폴더 이름은 먼저 `--list`로 확인하세요.

### 2. 검증 실행

가상환경을 켠 상태에서 프로젝트 폴더(AI)에서 실행합니다.

```bash
python tools/eval_ear_photos.py --list
```

```bash
python tools/eval_ear_photos.py
```

얼굴을 못 찾은 사진이 많으면 여백을 늘려서 다시 실행해 봅니다.

```bash
python tools/eval_ear_photos.py --margin 0.5
```

### 3. 결과 (숫자만 저장, 사진은 저장 안 함)

| 파일 | 내용 | GitHub |
|---|---|---|
| `results/ear_threshold_accuracy.csv` | 기준값(0.10~0.30)별 정확도 | 올려도 됨 (숫자 요약만) |
| `data/results/ear_per_image.csv` | 사진별 EAR 값 | 안 올라감 (데이터셋 파일 이름이 들어 있어서 `data/` 안에 둠) |

### 정확도 표 읽는 법

| 열 | 뜻 |
|---|---|
| 전체 정확도 | 얼굴을 찾은 사진 중 눈 뜸/감음을 맞힌 비율 |
| 감은 눈 맞힘 | 눈 감은 사진을 "감음"으로 맞힌 비율 (높을수록 졸음을 놓치지 않음) |
| 뜬 눈 맞힘 | 눈 뜬 사진을 "뜸"으로 맞힌 비율 (높을수록 잘못된 졸음 경고가 적음) |

기준값을 올리면 감은 눈은 더 잘 잡지만, 뜬 눈을 "감음"으로 잘못 보는 경우도 늘어납니다.
두 값이 함께 높은 기준값이 좋은 기준값입니다.

### 주의: 사진 검증과 실제 사용의 차이

- 데이터셋 사진은 **다른 사람들의 얼굴**입니다. 내 눈에 맞는 값은 `c` 키 보정으로 따로 정하는 것이 좋습니다.
- 사진 한 장으로 판단하므로, 실제 프로그램의 "1.5초 이상 감으면 졸음" 같은 **시간 조건은 검증하지 않습니다.**
- 얼굴만 꽉 차게 잘린 작은 사진은 MediaPipe가 얼굴을 못 찾을 수 있습니다. 그래서 둘레에 여백을 붙여 분석합니다. 여백은 메모리에서만 붙이고 저장하지 않습니다. 못 찾은 사진 수는 따로 셉니다.
